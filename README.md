# Сертификаты и статьи по психологии и психосоматике — Наталья Светлакова

Персональный сайт-портфолио: сертификаты об образовании и статьи по психологии, психосоматике и семейным сценариям.

**🌐 Живая версия:** https://natalyasvetlakova.github.io/ns-psychology-profile/

---

## 📋 О проекте

Сайт состоит из двух разделов:

- **Сертификаты** — онлайн-галерея документов об образовании с указанием часов обучения и организации.
- **Статьи** — публикации по психологии, психосоматике и семейным сценариям с иллюстрациями.

**Особенности:**
- Светлая и тёмная темы с синхронизацией между страницами.
- Адаптивная вёрстка — работает на телефоне, планшете и десктопе.
- SVG-иконки, плавные анимации, кнопка «Наверх».
- Единый тёплый бордовый стиль.

---

## 🔒 Архитектура репозиториев

Проект использует **разделение на приватный и публичный репозитории**:

| Репозиторий | Видимость | Назначение |
|---|---|---|
| `psychology-certificates` (этот) | **Private** | Исходный код, история, черновики, конфигурации деплоя |
| [`ns-psychology-profile`](https://github.com/NatalyaSvetlakova/ns-psychology-profile) | **Public** | Готовый сайт (HTML, CSS, JS, файлы сертификатов и статей) |

Деплой происходит автоматически через **GitHub Actions**: при каждом `git push` в приватный репозиторий обновлённые файлы публикуются в публичный, а оттуда — на GitHub Pages.

**Что это даёт:** исходники, история правок и конфигурация скрыты от посторонних; наружу отдаётся только готовый сайт.

## ✨ Возможности

### Страница сертификатов (`index.html`)
- Автоматическая загрузка сертификатов через GitHub API из папки `certificates/`.
- Поддержка изображений (JPG, PNG, WebP, GIF) и PDF (превью через `pdf.js`).
- Отображение часов обучения на плашке.
- Красивые названия и описания — задаются в объектах `TITLES`, `META`, `HOURS`.
- Сортировка по дате (новые сверху).

### Страница статей (`articles.html`)
- Список статей загружается из `articles.json`.
- Карточки в стиле сертификатов: плашка «СТАТЬЯ», дата, обложка, название.
- Автоматическая сортировка по дате.
- Клик по карточке → открытие полной статьи внутри сайта.

### Страница статьи (`articles/texts/*.html`)
- Текст хранится в обычном `.txt` — писать можно без HTML-тегов.
- Автоматический парсер превращает текст в красивую вёрстку.
- Поддержка маркеров: `## Заголовок`, `### Подзаголовок`, `**жирный**`, списки, `[author:...]`, `[img:...]`.
- Автоматические кликабельные ссылки.
- Выравнивание по ширине с переносами по слогам.

### Общее для всех страниц
- **Светлая и тёмная темы** с сохранением в `localStorage` — единая на всём сайте.
- **SVG-иконки** вместо эмодзи.
- **Адаптив** — 3 колонки → 2 → 1 на мобильных.
- **Кнопка «Наверх»** — плавно появляется при скролле.
- **SEO**: Open Graph, `description`, `sitemap.xml`.

## 🚀 Как добавить новый сертификат

1. Положить файл в папку `certificates/`.
2. Назвать по шаблону: `certificate_ДД.ММ.ГГ.jpg` (например, `certificate_25.12.26.jpg`).
3. Добавь строку в объект `TITLES` в `index.html`.:
   ```javascript
   'certificate_25.12.26': 'Сертификат «Название курса»',
   ```
4. При желании добавить запись в `META` (кто выдал и год) и `HOURS` (количество часов):
   ```javascript
   'certificate_25.12.26': 'Международная Школа Арт-терапии · 2026',  // META
   'certificate_25.12.26': 8,                                        // HOURS
   ```
5. Закоммитить и запушить — сертификат появляется на сайте автоматически.

## 📝 Как добавить новую статью

### Шаг 1. Создать `.txt` файл с текстом

В папке `articles/texts/` создать файл, например `my-article.txt`. Написать обычный текст:

```
## Заголовок статьи

[author:Светлакова Наталья|психолог, психосоматолог, кандидат медицинских наук]

[img:my-article.jpg]

Первый абзац. Между абзацами — пустая строка.

Второй абзац с **важной мыслью**.

## Подзаголовок раздела

- пункт списка
- ещё пункт

Ещё текст со ссылкой: https://example.com
```

**Маркеры разметки:**

| Что пишешь | Что получится |
|---|---|
| `## Заголовок` | Крупный заголовок статьи или раздела |
| `### Подзаголовок` | Подзаголовок поменьше |
| Пустая строка | Новый абзац |
| `**текст**` | **Жирный текст** |
| `- пункт` | Пункт маркированного списка |
| `[author:Имя\|роль]` | Строка автора под заголовком |
| `[img:файл.jpg]` | Картинка из `articles/images/` |
| `https://...` | Станет кликабельной ссылкой |
| `\|\|` | Принудительный перенос строки |

### Шаг 2. Загрузить иллюстрацию

Скопировать картинку в `articles/images/`, назвать латиницей через дефис: `my-article.jpg`.

### Шаг 3. Создать HTML-обёртку

Скопировать `anxiety.html` → переименовать в `my-article.html` → открыть и найти в `<script>`:

```javascript
const FILE = 'anxiety.txt';
```

Заменить на:

```javascript
const FILE = 'my-article.txt';
```

Поправить `<title>` и `<meta name="description">` в `<head>`.

### Шаг 4. Добавить в `articles.json`

```json
{
  "title": "Заголовок статьи",
  "date": "2026-10-15",
  "description": "Короткое описание для карточки.",
  "tags": ["психология", "тема"],
  "image": "articles/images/my-article.jpg",
  "url": "articles/texts/my-article.html"
}
```

Закоммитить и запушить — статья появится на `articles.html`.

## 💻 Локальный запуск

Из-за политики CORS нельзя просто открыть `index.html` двойным кликом — `fetch()` не сработает.

**Способ 1 — Live Server (рекомендую):**
1. Установить расширение **Live Server** (Ritwick Dey) в VSCode.
2. Правой кнопкой на `index.html` → **Open with Live Server**.

**Способ 2 — через терминал:**
```bash
python -m http.server 8000
```
Затем открыть `http://localhost:8000`.

## 🚢 Деплой

Деплой **автоматический**. После `git push` в этот репозиторий:

1. GitHub Actions запускает workflow **Deploy to Public Repository**.
2. Файлы публикуются в `ns-psychology-profile`.
3. GitHub Pages публикует сайт.
4. Через 1–2 минуты изменения видны на https://natalyasvetlakova.github.io/ns-psychology-profile/.

Проверить статус: [Actions](https://github.com/NatalyaSvetlakova/psychology-certificates/actions).

**Обычный рабочий процесс:**
```bash
git add .
git commit -m "Описание изменений"
git push
```
